# path.md sentence-to-cell map

One row per normative unit of docs/library/path.md, as of 2026-11-25, naming the cell in this directory that covers it. Run with `python3 conformance/cases.py conformance/library/path`; every cell passes on the interpreter and the compiled build. `io_path1` (the 2026-11-20 io pass) and `pt_path1` (2026-11-21, then checked against Rust's `std::path`) are moved here; since the 2026-11-20 ruling `parent` follows Python's `PurePath.parent` for a `.` component, so `pt_path1`'s `a/./b` and `../x/./y` rows now read as the page says rather than as Rust does. `path_every_function_over_edge_paths` matches a Python mirror of the page on every line but one: `parent("/usr//lib/./x")` is `/usr//lib`, a view into the argument, where the mirror rebuilds `/usr/lib`; the page promises a view, so the view is right. Each expectation was checked live: with every `.out` and `.refused` perturbed, each of the 9 cells fails. Nothing here fails and nothing needed a fix.
