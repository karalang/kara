# io.md sentence-to-cell map

One row per normative unit of docs/library/io.md (each prose sentence, each table row, each code block), as of 2026-11-25, naming the cell in this directory (or the test elsewhere) that covers it. Run with `python3 conformance/cases.py conformance/library/io`; every cell passes on the interpreter and the compiled build. Each run starts in a fresh, empty working directory. `io_*` are the 2026-11-20 programs moved here: the io pass's own (their expectations re-checked against the page) and the self-contained ones of that day's network pass (`io_net_*`, whose outputs both backends agreed on then and agree on now). The rest are new in this audit. The network, TLS, WebSocket and HTTP sections need a peer process (a Python client, a TLS client, a proxy), which `cases.py` cannot start, so their rows name the Rust tests and `conformance/tls_client.py` that drive one; the 2026-11-20 peer-driven programs stay with those tests' coverage. Each expectation was checked live: with every `.out`, `.err`, `.refused`, `.exit` and `.effects` perturbed, each of the 97 cells fails. The 2026-11-20 io pass's env and time cells belong to time-random-env.md and are not here.

**Fixed in this audit.** The interpreter stopped with `expected a sequence, found Agg(..)` when a fixed byte array reached a library native by value (`f.write(b"hello")`, `conn.write_all(b"ping")`, `String.from_utf8(arr)`), while the build ran it: B-2026-11-25-32, pinned by tests/interp_array_by_value_natives.rs. The I/O natives that return a new `String` or `Vec`, or grow the one they are given (`fs.read_to_string`, `fs.read_bytes`, `fs.read_dir`, `fs.read_lines`, `fs.read_link`, `stdin.read_line`, `env.args`, a `BufReader`'s line reads, `read_to_end`, the HTTP client's requests, a WebSocket's receives), were not charged `allocates(Heap)`, so `#[no_effect(allocates(Heap))]` accepted a function that reads a file: B-2026-11-25-33, pinned by tests/effects_io_natives_allocate.rs. The page's two example programs left `allocates(Heap)` out of their inferred effects; the page now lists it.

`Stdio.from_file` of a file a `FileSystem` fake opened stopped the interpreted program with an internal error and exit 3, where the build prints one `error:` line and exits 101; the interpreter now does as the build: B-2026-11-25-34, pinned by tests/interp_fake_file_child_stream_exit.rs.

**Still failing, filed.** B-2026-11-25-35 (sentences 8 and 9): a write through a `File` parameter is keyed by the argument when two `par` branches meet (both cells pass), but `pub fn put(f: ref File) -> bool with writes(f) blocks` is refused E0400 for want of `writes(FileSystem)`, `karac query effects` shows `writes(FileSystem)`, and a `TcpStream` read is charged `sends(Network)` beside `receives(Network)`.

**Gaps with no cell:** `exists` and `set_modified` on an unreadable file (the suite runs as root), `set_modified` leaving the access time and following a link, pipelined requests, `send_ping`, a handler that is not `CrossTask`, and the Windows and wasm_wasi sentences.
